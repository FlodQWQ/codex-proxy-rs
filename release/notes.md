# v3.13.1-Flod-fork.3

## 模型指纹检测

- 账号页新增 ModelTrace 指纹检测，可选择 OpenAI 账号和模型；固定题库随在线更新安装到本地
- 三条有效回答且归因置信度至少 70% 才生成降智观测，沿用三小时标记与缓解逻辑；不保存测试原文
- 首次检测时在本地准备 Python 分析环境，更新页面会显示检测与安装结果

## 升级说明

- 可从同一 Flod-fork 通道在系统设置中检查并更新；GitHub 发版不会自动更新运行中的 VPS
- 在线更新会保留现有配置、数据库及 `.runtime` 数据；ModelTrace 题库仅在本地缺失时安装

## 账号额度

- 账号页在可归属的 5 小时、7 天额度窗口内显示本地账号消费，并以统一的 0.2× 倍率显示用户折算值；无法计价或只能部分计价时明确标记
- 金额沿用请求发生时记录的本地费用，账号消费不代表上游订阅账单；用户折算仅供查看，不改变 Client Key 的实际扣费或历史账本

## 升级说明

- 本版无需新增配置或数据库迁移；从同一 `Flod-fork` 通道的上一版可以在线检查更新
- 运行中的 VPS 不会因 GitHub 发版自动升级；手动安装时使用本版归档、`SHA256SUMS` 和 `update-cpr.sh`，升级前备份数据库
