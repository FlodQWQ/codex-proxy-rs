# v3.12.1-fork.19

## 打票修复

- 292 票据本地缓存上限调整为 240 秒，提前 60 秒续期；这是根据实测反馈采用的保守上限，不代表上游保证的有效期
- 打票与业务请求复用当前账号的路由 Cookie，支持保存和回放 `__cflb`、`__oailb`，遵守域名、路径、Secure 和过期限制，不跨账号共享
- 先保存 Cookie 再发布票据；缺少有效路由 Cookie 或保存失败时拒绝发布新票据，业务请求也不单独发送无 Cookie 的票据
- Go 打票组件回传多条 `Set-Cookie`，Cookie 不发送给出口 IP 查询；保留 HTTP 429 后全账号模型暂停打票一小时的行为及近一小时统计窗口

## 升级说明

- 必须同时更新主程序与 `codex-ticket-probe`，完整升级包包含两者及前端、手动更新与迁移脚本
- 旧版一小时票据缓存升级后失效，需要重新采集；已有配置和账号数据保留，本次不新增数据库迁移
- 保留此前账号改名和完整定制包在线升级能力，更新检查继续使用本 fork
- 升级产物仅发布到 FlodQWQ/codex-proxy-rs，不自动升级运行中的服务
