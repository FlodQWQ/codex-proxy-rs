# v3.13.1-Flod-fork.5

## 账号额度与重置

- 账号页显示上游 OpenAI Credits 余额及额度状态。
- Reset 入口显示查询状态和可用次数，支持查看重置卡并执行额度重置。
- 本地用量金额明确标记为周期估算费用，避免与上游余额混淆。

## 指纹检测稳定性

- 账号检测最多并发 3 个，避免一次性压满上游代理导致 524
- 诊断请求临时绕过账号日常并发数与请求间隔限制
- 已知额度耗尽的账号自动跳过，不再浪费检测请求
- 扩大目标模型选择栏，完整显示模型名称

## 模型指纹检测

- 账号页新增 ModelTrace 指纹检测，可选择 OpenAI 账号和模型；固定题库随在线更新安装到本地
- 三条有效回答且归因置信度至少 70% 才生成降智观测，沿用三小时标记与缓解逻辑；不保存测试原文
- 首次检测时在本地准备 Python 分析环境，更新页面会显示检测与安装结果

## 升级说明

- 可从同一 Flod-fork 通道在系统设置中检查并更新；GitHub 发版不会自动更新运行中的 VPS
- 在线更新会保留现有配置、数据库及 `.runtime` 数据；ModelTrace 题库仅在本地缺失时安装
- 本版新增降智观测迁移；升级前请备份数据库
